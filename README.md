ETHIO•KCAL — Meat vs Vegetable Entrées Comparison Tool
Cinematic, culturally authentic nutrition insights for Ethiopian cuisine
ETHIO•KCAL is a premium, data‑driven nutrition companion designed to help users understand Ethiopian meals with clarity, cultural pride, and visual elegance.
This module — Meat Entrées vs Vegetable Entrées Comparison — allows users to compare calories and macros side‑by‑side across traditional dishes, helping them build balanced, intentional plates.

🌟 Features
1. Side‑by‑Side Macro Comparison
Compare one meat entrée and one vegetable entrée directly:

Calories

Protein

Carbs

Fat

Δ (difference) values for each macro

Visual A/B comparison panel

2. Three‑Column Meal Builder
The interface is structured into three intuitive columns:

Column A — Primary (Meat Entrée)

Column B — Lighter (Vegetable Entrée)

Column C — Complement (Side Dish)  
Each column displays approximate per‑serving macros for traditional Ethiopian dishes.

3. Live Plate Guidance
A dynamic guideline shows where most Ethiopian plates land:

1,100–1,600 kcal typical full‑plate range

Visual meter from 0 → 2,000 kcal

4. Swap & Compare
Instantly swap Dish A and Dish B to reverse perspectives without reselecting items.

5. Add to Plate Summary
Users can add selections to their daily plate summary for deeper tracking across the ETHIO•KCAL ecosystem.

🚀 How It Works
User selects a meat entrée (e.g., Doro Wat, Tibs, Kitfo).

User selects a vegetable entrée (e.g., Misir Wat, Gomen, Atakilt).

ETHIO•KCAL displays:

Per‑dish macros

A/B visual comparison

Δ differences

User optionally selects a side dish to complete the plate.

User adds items to their plate summary for daily totals.
